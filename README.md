# Proejto_Uber
 O projeto entrega uma visão operacional clara da plataforma, ajudando a identificar pontos críticos (cancelamentos, satisfação, escolha de veículos) e oportunidades de melhoria no atendimento.

🚖 Análise Operacional da Plataforma de Compartilhamento de Viagens

Este projeto integra SQL e Power BI para realizar o tratamento de dados, modelagem e visualização de uma base de operações de uma plataforma de carona.
O objetivo é fornecer uma visão completa das operações , incluindo viagens bem-sucedidas, cancelamentos, comportamento dos clientes e métricas financeiras .

📌 Objetivo do Projeto

Criar uma análise descritiva e dashboards interativos para responder perguntas de negócio e fornecer insights operacionais, auxiliando na tomada de decisão.

🛠️ Tecnologias Utilizadas

MySQL → Criação, normalização e tratamento das tabelas

SQL → Análise descritiva, estatísticas e limpeza de dados

Power BI → Modelagem de dados e construção de dashboards interativos

DAX → Criação de medidas para análises avançadas

📊Principais Perguntas Respondidas

Clientes com baixa avaliação cancelam mais corridas?
✔️ Sim, especialmente quando o cancelamento é feito pelo motorista.

Qual a relação entre o tipo de veículo e a avaliação recebida?
✔️ Premier Sedan e Go Sedan são os mais bem avaliados; Go Mini é o mais utilizado.

Distância percorrida influencia na satisfação do cliente?
✔️ Sim, os clientes estão mais satisfeitos em corridas mais longas (20+ km).

Tempo médio de chegada impacta satisfação?
✔️ Os clientes ficam mais satisfeitos quando o motorista chega entre 11–15 minutos .

Principais motivos de cancelamento?
✔️ Problemas de localização, motorista não enviando deslocamento e endereços incorretos são os mais comuns.

Corridas de alto valor têm maior taxa de cancelamento?
❌ Não, elas têm menor taxa de cancelamento , indicando que são viagens mais planejadas.


Resultados

✅ Visão operacional clara da plataforma
✅ Identificação de pontos críticos (cancelamentos, avaliações, métodos de pagamento)
✅ Apoio para decisão estratégica e melhoria da experiência do cliente
